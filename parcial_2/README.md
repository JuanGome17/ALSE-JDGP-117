# Proyecto C++ - Gestión de Estudiantes

## Descripción
Este proyecto implementa una clase Student usando programación orientada a objetos en C++.

## Características
- Uso de clases separadas en .h y .cpp
- Uso de STL (vector)
- Validación de datos
- Documentación con Doxygen
- Compilación con CMake

## Compilación

```bash
mkdir build
cd build
cmake ..
make
./Proyecto
